# board（アプリ群のひとつ）

正本DBの状態を見るための、**読み取り専用**のボードです。本体(private)の `board/` を
公開用に移植したもので、[SmartHR Design System](https://smarthr.design/) /
[smarthr-ui](https://github.com/kufu/smarthr-ui) に準拠しています。

アプリは全部で8本あります(`board` `insight` `status` `inbox` `people` `prep` `profile` `impact`)。
どれも同じ構成・同じ共有層([shared/](../shared/))で、ここに書いた設計は全部に当てはまります。

> このプロジェクトは SmartHR 社とは無関係です。OSS として公開されているデザインシステムと
> コンポーネントライブラリを利用しているだけで、SmartHR のロゴ・ブランドは使用していません。

## 設計

このリポジトリの原則「**書き手はエージェントだけ。画面は見る窓**」をUIの構造で守っています。

- **DBへ触りません。** 本人が連携した保存先の認証付きAPIから閲覧データを取得します
- **DBへの書き込みボタンはありません。** 状態を変えるのはエージェントと本人だけです
- **データは認証が必要です。** 保存先と画面のoriginに結び付いた30分間のセッションで閲覧します。
  切り替え・解除・期限切れで画面内のデータを消します
- **出さないものがあります。** マイページのログインID・パスワード、顔写真の実体、メール本文は
  スナップショットに含めません

「自動ログイン設定」はWindows PCの端末設定画面への入口です。`npm run local-login:settings` で起動した
127.0.0.1のサーバーを通じて、本人がサービス名・URL・認証方法・実行予約を設定します。
この画面はDBを読み書きせず、通常の閲覧画面から分けて読み込みます。
詳細は[自動ログインの設定](../scripts/local-login/README-daily-login.md)を参照してください。

## タブ（本体と同じ構成）

| タブ | 中身 |
|---|---|
| きょう | 14日以内の予定 / 未提出の締切(残り日数つき) / 結果・案内の待ち。名寄せの確認待ちがあればここに出る |
| 選考 | 全トラック。状態は `outcomeOf()` の機械判定を `StatusLabel` で表示 |
| 企業 | 企業ごとに畳んだ一覧。開くと正式名称・トラック・企業研究の要約・マイページ |
| ログ | イベント台帳(`event`)。「なぜ今この状態か」を後から追うための行 |

「きょう」の確認待ちに出るのは、たとえば `合同会社ガンマ` が既にあるところへ `株式会社ガンマ` が
来たケースです。エージェントは自動でマージせず、ここへ積みます
(設計は [`resolveCompany`](../src/db.ts) を参照)。

## 開発者向けの確認

画面だけで導入するPCアプリは準備中です。[一般利用者向けの案内](../docs/GETTING-STARTED.md)とは区別してください。

```sh
# 1. 自分の正本DBから非公開の data/snapshot.json へ書き出す
npm run snapshot

# 2. 開く(どのアプリでも同じ)
cd board
npm install
npm run dev
```

アプリ間のリンク(左サイドバー)は兄弟ディレクトリへの相対パスです。開発サーバーは
アプリごとに別ポートなので飛べません — 本体と同じ制約です。ビルドして1か所へ
並べると繋がります。

[保存先の手動設定](../docs/CLOUDFLARE-SELF-HOSTING.md)後、画面の詳細設定から接続します。
実データを `public/` に置くことは禁止し、Viteのビルド前後で検査します。架空データは同梱しません。

## 依存について

コア(`src/`)は**ランタイム依存ゼロ**のままです。各アプリは自分の `package.json` を持ち、
npm パッケージ `katazuku-shukatsu` には含まれません。コアを使うのに React も SmartHR UI も要りません。

共有データ層 `@katazuku/data` は `../shared/src/index.ts` を Vite のエイリアスで直接読みます
(ビルドしません。本体と同じ構成)。
