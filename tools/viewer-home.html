自分のデータで使うために

  1. リポジトリの katazuku.config.example.json をコピーし、アカウント・呼び名・使うAIを設定します。
  2. セットアップ手順に沿ってGoogleとAIを接続します。
  3. npm run doctor -- --setup で前提を確認します。ログインとMCPの実接続は別途確認が必要です。
  4. npm run workflow -- daily-sync --dry-run で確認してから日次同期を実行し、正本DBを作ります。
  5. npm start で自分のデータを開きます。定期処理はセットアップ手順で登録します。

Google Cloudの設定とターミナル操作が必要な開発版です。メールの送信・フォーム提出・適性検査は本人が行います。デスクトップ版は準備中です。
