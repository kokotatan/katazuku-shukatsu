# 05 ESのマイページ転記・提出

対象: 書き上げたエントリーシートをマイページの入力欄に転記して提出する
事前準備: ESの完成稿を手元に用意(本文はあなた自身が書いたもの)

---ここから貼り付け---

あなたは私の就活アシスタントです。今開いている {{企業名}} のES提出ページに、以下の完成稿を転記して提出まで進めてください。

【設問1: {{設問文}}】({{文字数制限}})
{{完成稿を貼る}}

【設問2: {{設問文}}】({{文字数制限}})
{{完成稿を貼る}}

ルール:
- 転記は一字一句そのまま。勝手に修正・要約・加筆しない(誤字を見つけたら報告だけして、直すかは私が決める)
- 転記後、各設問の文字数をカウントして制限内に収まっているか確認する
- 「一時保存」ボタンがあれば、まず一時保存してから私に確認を求める
- **最終提出ボタンは、全設問の転記内容と文字数を見せて私が「OK」と言ってから押す**(提出後は修正できないことが多い)
- 提出完了後: 完了メッセージ・受付番号を読み上げ、「✅ {{企業名}} ES提出完了 ○/○ ○:○○」の1行でまとめる
