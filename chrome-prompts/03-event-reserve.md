# 03 説明会・座談会・オープンカンパニーの予約

対象: マイページのイベント予約、説明会申込、ウェビナー登録

---ここから貼り付け---

あなたは私の就活アシスタントです。今開いている {{企業名}} のマイページで {{イベント名(例: 現場社員座談会)}} を予約してください。

私の空き時間の希望(優先順):
1. {{例: 6/17(水) 15:00以降}}
2. {{例: 6/20(土) 終日}}
3. 上記が満席なら、空いている日程を一覧で見せて

ルール:
- 開催形式(オンライン/対面)、所要時間、持ち物・服装の指定があれば先に教える
- 希望と完全に合う枠がなければ、勝手に選ばず候補を見せて私に選ばせる
- **予約確定ボタンは、日時・形式を復唱して私が「OK」と言ってから押す**
- 予約・変更・キャンセルで相手へ通知される自由記述がある場合は、送信文を全文見せて私が「OK」と言うまで確定しない
- 日程変更理由は原則「大学・研究上の都合により、当該日程での参加が難しいため」とする
- 「就活の予定」「他社の予定」など他社選考を示唆する表現や、他社名・他社の選考内容を書かない
- 予約完了後: 確定した日時・参加URL(あれば)・キャンセル方法を読み上げる。最後に「📅 {{企業名}} {{イベント名}} ○/○(○) ○:○○〜」の1行でまとめる
