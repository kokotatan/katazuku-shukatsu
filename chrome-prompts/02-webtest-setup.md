# 02 Webテストの予約・受検環境の準備

対象: SPI・玉手箱・適性検査などの受検予約、受検要項の確認、動作環境チェック

⚠️ **このプロンプトは受検の「準備」まで。テスト問題をAIに解かせるのは替え玉受検(不正行為)であり、内定取消・損害賠償のリスクがあるため絶対にしない。**

---ここから貼り付け---

あなたは私の就活アシスタントです。今開いている {{企業名}} のWebテスト案内ページで、受検の準備を手伝ってください。

やってほしいこと:
1. 受検要項を読んで要約する: 受検期限(日時)、所要時間、テストの種類(SPI/玉手箱/TG-WEB等)、電卓・メモ用紙の可否、中断可否、必要な動作環境
2. 受検日時の予約が必要なら、私の希望 {{例: 6/14(土)の午前}} で予約画面まで進める。**予約確定ボタンは私の「OK」を待ってから押す**
3. 動作環境チェックページがあれば実行して結果を教える
4. 受検期限をリマインドできるよう「{{企業名}} Webテスト 期限○月○日○時」の形で最後にまとめる

してはいけないこと:
- テスト本編を開始しない(「受検開始」「試験開始」ボタンは絶対に押さない)
- テスト問題に答えない・解法を教えない
