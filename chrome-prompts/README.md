# 🌐 Claude in Chrome 操作プロンプト集

マイページでの提出・予約・日程回答などのブラウザ操作を、Claude in Chrome(Chrome拡張)にやらせるためのプロンプト集。

## 使い方

1. **個人マスタは `submit.local.md` の§4〜§11**(gitignore済み)。氏名・学歴・職歴・資格・受賞・ES素材まで全部ここで管理する(旧 `_profile.local.md` は廃止)
2. Chromeで対象のマイページ・フォームを開く
3. `katazuku submit` / `katazuku test` でプロンプトをコピーするか、目的のプロンプトを手でコピペ
4. 01〜04のプロンプトで個人情報が要る場合も `submit.local.md` の該当節を貼る

## プロンプト一覧

| ファイル | 用途 |
|---|---|
| `01-entry-form.md` | エントリーフォーム・応募フォームの入力と提出 |
| `02-webtest-setup.md` | Webテストの予約・受検環境の準備(※問題を解かせるのは不可) |
| `03-event-reserve.md` | 説明会・座談会・オープンカンパニーの予約 |
| `04-schedule-reply.md` | 面接・面談の日程調整フォーム回答 |
| `05-es-submit.md` | 書き上げたESのマイページ転記・提出 |

## ⚠️ 全プロンプト共通のルール(各プロンプトに組み込み済み)

- **送信・提出ボタンを押す前に、必ず入力内容を一覧で見せて確認を取る**(取り消せない操作を勝手にしない)
- 個人情報は `_profile.local.md` の値のみ使い、推測で埋めない。不明な項目は質問する
- **Webテスト・適性検査の問題をAIに解かせるのは不正行為(替え玉受検)**。経歴詐称と同様に内定取消・損害賠償のリスクがあるため、このプロンプト集は予約・環境準備までしか扱わない
