# 08 ブラウザエントリー代行の技術知見(Claude in Chrome / claude-in-chrome MCP)

2026-07-10 の実戦(任天堂プレエントリー e2r / 日本トレカセンター HRMOS)で得た再現性のある操作知見。
モデルが変わっても(Fable→Opus等)同じ手順で作業できるよう、ここに焼き込む。

## 大原則

- 個人マスタは `submit.local.md` §4〜§11。送信ポリシー・パスワード規約も同ファイル §0。
- **パスワード設定・アカウント認証だけは代行不可**(Claude Codeの安全ルール)。
  パスワード入力画面まで進めてタブを残し、本人に「この画面だけ入力して」と引き継ぐ。
  ワンタイムコード(メール宛)は Gmail MCP で自分で取得できる。SMS宛は本人へ。
- 応募系の同意チェック(個人情報・肖像権等)は、本人からエントリー依頼があれば
  エントリーに必須の範囲で同意してよい。**何に同意したかを最終報告に必ず書く**。

## 座標クリックの罠(最重要)

- `computer` のクリック座標は**直前のスクリーンショットのピクセル座標をそのまま使う**のが基本だが、
  ずれる事例を複数確認した(1フィールド分=約100px下にずれる等)。
- 対策: **「クリック1回 → 検証スクショ」を徹底し、連続クリックで一気に埋めない**。
  テキスト欄はまず1文字テスト(例: "A")でフォーカス位置を確認すると確実。
- `triple_click` は `left_click` と着弾点がずれることがある。クリア目的なら `ctrl+a` を使う。

## 確実に効いた入力パターン

- **click → ctrl+a → type → wait(1s) → Tab → type → ...** のTab移動方式が最も安定。
  日本語(漢字・カナ)もこの方式なら入る。クリック直後の即typeは日本語が消えることがある。
- native `<select>` はフォーカスして数字/文字を type すると先頭一致で選択される
  (生年月日 2003/7/25、在籍期間 2026/4〜2028/3 で実証)。矢印キー+zoomで1個ずつ確認も可。
- ラジオボタンはクリックが効かないことがある。**選択中のラジオをクリック→矢印キーで移動**が確実。
- 選択結果の確認は `zoom` で対象領域だけ拡大表示すると速い。

## サイト別の突破法

### e2r (eARTH。任天堂ほか採用サイト共通基盤)

- 「同意する」等のボタンは `target=_blank` で **MCPタブグループ外**に開く。
  `location.assign(a.href)` で同タブ遷移に変える(hrefは読めなくてもJS内で使える)。
- 学校検索ポップアップは `window.open` をフックして URL を捕まえ、**同タブで直接遷移**して
  検索フロー(種別→ふりがな→学校→研究科→専攻→確認)を進める。
- 確認画面の `Submit()` は `opener.document.mainform.I22/I23/I24(_chk)` に**プレーンな学校名文字列を
  書くだけ**(学校コード不要)。つまり FirstRegist 側で I22〜I24 と各 `_chk` hidden に直接値を
  入れれば学校検索を丸ごとスキップできる。
- フォーム項目はID規則 `I<番号>(_D<分割>)`。JSで `value` 設定 + `input`/`change` dispatch で通る。
- **iframe内で submit する実験は禁止**: alert が出るとタブ全体がフリーズし復旧不能
  (タブを閉じて最初からやり直しになる)。危ない操作の前に
  `window.alert=()=>{}; window.confirm=()=>true;` を仕込む。

### HRMOS (public.n-ats.hrmos.co)

- 応募フォームの直URL(`/jobs/<id>/apply`)は**求人タイトルが空になり項目も欠ける**。
  必ず**埋め込み元ページ(特設サイト)の iframe 経由**で操作する。
- cross-origin iframe は `read_page`/`find`/`form_input` が届かない。**座標クリック+キーボードのみ**。
- iframe の内部スクロールに苦しむより、**親ページから iframe を縦に広げる**:
  `iframe.style.setProperty('height','4200px','important')` + 祖先の `overflow:hidden` な要素に
  `height:auto` を設定。以後はページスクロールだけで全項目に届く。
- 演出の多い特設ページ(スクロール連動アニメ)は、実マウススクロール(上→下)でないと
  コンテンツが描画されないことがある。`scrollIntoView` 後に小さく実スクロールして起こす。

## 送信前チェック(submit.local.md §Step 6 に加えて)

- 確認画面のスクショを撮り、氏名/カナ/生年月日/連絡先/学歴/選択項目を目視検証してから送信。
- 送信完了画面の文言(受付完了・控えメール送付など)を最終報告に記録する。
