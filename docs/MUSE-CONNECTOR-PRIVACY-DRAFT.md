# katazuku Muse Connector プライバシー通知（公開前草案）

更新日: 2026-10-31

この文書はMuse Connector審査用の草案です。角括弧の事業者情報、公開URL、連絡先、保持期間、削除窓口を実運用に合わせて確定し、法務・運用確認を終えるまで公開通知として扱いません。

## 対象

本通知は、利用者が自分で運用するkatazuku Muse Connector（以下「本Connector」）をMuseへ接続した際のデータ処理に適用します。[事業者名]が提供する他サービスには、それぞれの通知が適用されます。

## 取得・処理する情報

利用者が許可したscopeと依頼に応じて、次を処理します。

- 応募先、選考状態、提出物、締切、予定、空き時間、移動・面談準備の状態
- メールのmessage/thread ID、送受信者、件名、日時、必要最小限の本文要約
- 利用者が明示的に許可したプロフィール、人物、面接・面談記録、企業研究
- MCP tool名、入力、結果、承認action hash、実行状態、エラー、Sent再照合証跡
- OAuth client、許可scope、認可・失効に必要な識別情報、rate-limitと再利用防止情報

メール資格情報、Apple Account password、app-specific password、OAuth refresh token、回復コード、Museのcredential surrogateは本Connectorへ取得・保存しません。適性検査の問題・解答も扱いません。

## 利用目的

情報は、利用者の依頼に基づき、就職活動の状態表示、正本への冪等な記録、日程競合判定、提出物追跡、面談準備、承認対象の固定、障害復旧、重複操作防止、セキュリティ維持、利用者サポートのためだけに利用します。広告、データ販売、無関係なプロファイル作成、利用者の依頼と無関係なモデル学習には利用しません。

## 保存場所と期間

- 就職活動データとworkflow証跡は、利用者が管理する端末または利用者指定の保存先に保持します。
- remote gatewayはMCP payloadと結果を永続化せず、所有者端末への中継中だけメモリで処理します。
- gatewayのOAuth認可情報、短期access token、rate-limit状態、再利用防止hashは、認証と不正利用防止に必要な期間だけ保持します。
- 具体的な保持期間: [正本DB] / [workflow証跡] / [OAuth認可] / [セキュリティログ]。

利用者がアクセスを取り消したとき、削除を求めたとき、または目的に不要になったときは、法令上またはセキュリティ上保持が必要なものを除き、対象情報を削除またはアクセス不能にします。

## 共有と委託

依頼の遂行に必要な範囲でMuseおよび利用者が選択した基盤事業者へ送信します。各受領者へ、本Connectorが持つ範囲を超える利用目的・アクセス・保持権限を与えません。提供先候補と役割は[公開する一覧]に記載します。

## セキュリティ

TLS、OAuth scope、PKCE、短期token、Origin/Host検査、rate limit、端末側allowlist、loopback MCP、入力上限、秘密値非出力、action hash、冪等性、Sent再照合、`unknown`時の再送停止を使用します。資格情報はMCP引数、応答、URL、ログ、正本DBへ保存しません。

## 利用者の選択と削除

利用者はRead Onlyから開始し、`write`、`sensitive`、`actions`を個別に許可できます。Museまたは本Connectorの設定から認可を取り消せます。開示、訂正、削除、接続解除は[窓口と手順]へ依頼してください。本人確認に必要な最小限の情報だけを求めます。
