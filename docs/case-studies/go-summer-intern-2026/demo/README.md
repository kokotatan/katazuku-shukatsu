# 共同配車コントロールタワー

GOサマーインターン2026で制作した、GO LOGISTICS CLEARINGの操作デモです。30社の配送案件と車両を横断し、共同配送候補の発見、計画、運行、例外対応、実績確認までを一つの画面で体験できます。

## 起動

~~~powershell
npm ci
npm run dev
~~~

## 検証

~~~powershell
npm run build
npm run test:sites
~~~

## 主な画面

- ライブ管制
- 配送計画
- 例外対応
- 会社・車両
- 実績レポート
- システム構成

固定データによるプロトタイプです。実際のTMS、車載器、最適化エンジン、外部API、決済には接続していません。
