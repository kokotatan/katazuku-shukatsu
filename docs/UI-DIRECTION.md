# private版のUI方針（2026-09-08）

本人の指示: まずprivate版を使いやすく整え、その後にOSSへ展開する。過剰な説明やAI生成にありがちな装飾を避ける。

活動記録の本人指示（2026-09-08）: 日付から、その日に何があったかを振り返れることを優先する。月のカレンダーと日別の時刻順の記録を基本とし、メール対応・会話や作業の保存済みメモ・予定・面接等を読む。自動処理の反復ログはまとめて開く。スマホでは日付から記録へ移動でき、カレンダーへ戻る入口を置く。架空の出来事を補わず、受信と返信、予定と実施記録を混同しない。現時点の表示範囲は同期済みの記録と要約で、ターミナルの会話全文の自動取込は未接続。

- 基本部品はSmartHR、システムフォントと罫線中心の見た目を維持する。配色は本人の最新指示によりネクタイロゴの青（主色 #005AFD、リンク #004BD6）と無彩色に合わせる。
- 画面は日常の操作を優先する。サービス紹介のコピーや公開中バッジは置かない。
- 操作先は日本語で示す。説明は区別に必要な短い一文にする。
- 日本人向けの日本語UIを前提にする。英語の短い単語で成立する見た目をそのまま基準にしない。長い企業名・件名が読める幅と行高、日付・状態の揃え方を優先する。
- 絵文字をUIの装飾・見出し・ナビに使わない。必要なアイコンは単色の統一した線画と日本語ラベルを使う（2026-09-08本人訂正）。
- 開発記録や端末設定は補助領域へまとめる。
- PCとスマホの表示、キーボード操作、ラベルを確認する。
- 制作名は `Kotaro Design Lab.`。プロダクト名 `katazuku` と区別する。説明は必要時に開く「使い方」へまとめ、画面上は短い項目名を優先する。
- 企業研究と、人の顔・会った場面・話したことを読む体験を重視する。スマホ下部は「今日・企業研究・人・メール・その他」の5項目。マネーフォワード MEを参考に、どの画面でも同じ位置から移動できるようにする。

今回の実装: ホームでは企業研究と人を先頭にし、説明文を除いた短い入口へ整理。7アプリの共通ナビ、配色、見出し、使い方を統一。企業研究は会社選択・日本語の調査項目・出典・面接記録・会った人を表示。人は検索と一覧・詳細、日付付きの全会話履歴を表示する。認証・正本DB・同期処理は変更していない。

企業ロゴは `dossier.facts.logoUrl` に確認済み素材がある場合に表示し、未登録時は社名の文字を表示する。現時点では各社の素材追加は未実施。「企業研究専用ロゴ」か「各社の企業ロゴ」かの確認を本人へ提示済み。人物写真は既存の認証付きAPI配信をそのまま使い、写真がない場合や読み込めない場合の代替表示を用意する。検証用のサンプルデータ・サーバーは `.tmp/ui/` に置き、配信物に含めない。

OSS v0.3.0には設定フォームに加えて8つの閲覧GUIがある。現状はローカルのsnapshot JSONを読む構成で、今回のprivate版の見た目と認証付きCloudflare接続の移植は別途扱う。

2026-09-08 合言葉入力前の表示（本人訂正）: 架空データを入れて操作できる表示例は不要。本人の要望は、[UIの状態設計の参考投稿](https://x.com/dezainaz_ceo/status/2096824984710836300)のように、画面の構成がうっすら伝わる入口。架空の会社・人物・件数・予定を生成する処理は削除する。8つの閲覧画面で、本来の見出し・列・行・区切りと、内容部分を示す静止した灰色の線だけを薄く表示し、手前に合言葉の入力欄を置く。未入力時はデータなし・API通信なし。背景は操作や読み上げの対象から外し、本人の情報は認証後にだけ取得・表示する。デモ・架空データ・表示例のバッジへ戻さない。

2026-09-08 細部の調整: 同じ「更新」ボタンの文言・44pxの操作高さ・80pxの固定幅を6画面で統一。更新中の幅変化を防止し、読んでいるデータを保持することを遅延・503の確認用サーバーで検証。合言葉入力は16px・44pxへ揃え、未入力時の送信を抑止した。研究の出典・面接記録は折りたたみ矢印と48pxの操作範囲を揃え、本文の列挙は罫線から箇条書きへ変更。PCの企業・人物一覧は長文を読んでも画面上部に残す。長い氏名・英字・肩書き、写真なし、320px幅も確認。日付の数字を等幅にし、補助情報の薄すぎる文字色を修正。ホームの「その他」も各画面と同じ縦のメニューへ統一した。
