# 閲覧中心のkatazuku-shukatsuをPC・スマホのアプリとして整える

調査日: 2026-09-08。対象はprivate版。日常の閲覧体験を先に改善し、検証後にOSSへ展開する。今回は公式の製品例・デザインガイドと既存コードを照合した設計調査であり、多人数のユーザーテストや利用頻度の計測ではない。

実装時の本人訂正: 配色はネクタイロゴの青、制作名はKotaro Design Lab.。企業研究と人を主要導線にし、下部ナビは「今日・企業研究・人・メール・その他」の5項目へ変更した。常設説明を減らして「使い方」に集約。以下には比較時の候補案も含むため、現在の実装方針は `UI-DIRECTION.md` を優先する。

## 推奨する方向

「今日の予定と確認事項をすぐ読める個人アプリ」にする。起動したら今日の内容が表示され、企業・メール・人物の詳細まで迷わず移動できる。現在のホームは入口の整理までで、目標とする完成形ではない。

本人の「日本人向けなので違う・絵文字はイケてない」という訂正を受け、参考を国内向けの日本語UIへ変更。SmartHRの件名・期限・状態の整列、マネーフォワード MEの確認の流れ、Sansanの企業・人物詳細を比較する。SmartHRの配色、システムフォント、コントラスト、罫線中心の表現を維持する。絵文字を装飾・見出し・ナビに使わず、必要なアイコンは単色の統一した線画と日本語ラベルにする。ブランドは以前作成したネクタイロゴに統一する。候補は提案段階で、本人の採用決定ではない。

## 画面構成の提案

| 項目 | PC | スマホ |
| --- | --- | --- |
| 起動時 | 今日の予定・要確認・近い締切 | 同じ情報を重要な順に一列で表示 |
| 主要移動 | 左サイドバー | 下部に「今日・選考・メール・資料」の4タブ案 |
| 一覧 | 日時・企業・用件・状態を揃えて比較 | 企業と用件を主行、時刻と状態を副行にする |
| 詳細 | 一覧の右側に表示 | 全画面で読む。短い補助情報だけボトムシート |
| 検索 | 見える検索欄＋キーボードショートカット | タップで検索画面を開く |
| 戻る | 選択項目・検索条件・スクロール位置を維持 | 同じ位置に戻る。端末の戻る操作にも対応 |
| 設定 | サイドバー下部 | 資料タブ内。頻繁に使う内容を設定へ隠さない |

「資料」は面接準備・自己PR・人物をまとめる案。人物閲覧が多ければ、人物を独立タブにする余地を残す。現時点では頻度の計測がなく、4タブが最適と実証されたわけではない。

閲覧中心なので、追加・編集の大きなボタンは置かない。予定を開く、会議に参加する、原文を見る、コピーする等、その情報を読んだ次の操作に絞る。第三者への送信・予約の承認境界は変えない。

## 見た目と操作の品質基準

- 背景は淡いグレー、読む面は白、主文字は十分に濃くする。青はリンク・選択、赤は本当に注意が必要な状態に限定する。
- 情報のまとまりは見出しと余白で表現し、すべてを角丸カードにしない。大きな数値カード、宣伝コピー、装飾目的のグラデーションは不要。
- スマホ本文は16pxを出発点にする。状態ラベルを小さくしすぎず、締切・企業名・用件を同時に読めるようにする。
- 押下・選択・フォーカス・読み込みの状態を揃える。短い遷移には目的を持たせ、prefers-reduced-motionに対応する。
- 読み込み中、予定なし、通信失敗、認証切れ、データ更新が古い状態を区別する。「取得できない」を「予定がない」にしない。
- 通知からは該当の予定やメールへ直接移動する。戻ったときの位置保持を検証する。
- PWAでは上端・下端の安全領域、縦横回転、キーボード表示、独立ウィンドウでの戻る動作を確認する。
- オフライン表示のために個人データを新しく永続保存する変更は、この外観改修に混ぜない。まず通信状態を正しく示す。

## 既存実装に見つかった差分

コード確認に基づく指摘。以下は実データを使った端末テストで再確認する。

1. ホームは7画面へのリンク集で、開いた瞬間に本人の予定を読めない。既存insightを初期画面へ統合する方が目的に合う。
2. insightの一覧では日時の固定幅、縮まない企業名、用件の省略が同じ横一列にある。長い企業名のスマホ表示で、読むべき用件が見えなくなる可能性がある。
3. insightの各行の「開く」は一律に `/board/` へ進む。対象の詳細へ直接進める必要がある。
4. ナビに英語の内部アプリ名、下部タブに10px文字が残っている。ホームだけでなく共通ナビを整える必要がある。
5. manifestにはstandaloneが既にあるが、全画面共通の戻る・復帰・読み込み体験が揃っていることまでは未検証。
