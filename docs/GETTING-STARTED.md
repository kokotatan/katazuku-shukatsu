# はじめて使う方へ

katazuku 就活は、予定、選考、メール、会話の記録をまとめて確認するアプリです。利用者ごとに、本人のPCと本人が連携した保存先のデータを使います。

**現在は導入確認中の開発版です。** Windows用のPC設定画面を実装しています。Googleのデータアクセス審査が未完了のため、警告が出ない一般向け完成版としてはまだ配布していません。公開サイトを開くだけで、PCの記録が取り込まれることはありません。

## PC設定画面での流れ

1. Windows用の配布フォルダを展開し、「katazukuの設定.vbs」をダブルクリックする。配布物にはNode.jsが含まれ、インストールやコマンド入力は不要。
2. PCで記録を保存するフォルダを選ぶ。自分のCloudflareへログインし、アカウントを確認して専用の保存先を作る。R2の利用設定はCloudflareの画面で本人が行う。
3. 「パスワードの設定画面を開く」から、katazuku用のパスワードを15文字以上で設定する。GoogleやWindowsのパスワードとは別。
4. PCの設定画面へ戻り、自分のGoogleアカウントを入力して連携する。Googleの画面で要求された権限を確認する。
5. 「アプリを開く」から、自分の記録を見る。スマートフォンでは、同じアプリのアドレスとkatazukuのパスワードを使う。

PC設定アプリの起動中は、記録の変更を毎分確認して保存先へ同期します。「今すぐ同期」も使えます。PCを再起動したら設定アプリを開いてください。同期できない場合はPCの記録を残し、画面に理由を表示します。

Cloudflareには無料枠があり、超過利用には料金が発生します。アプリが契約プランを変更することはありません。保存先の作成が途中で止まったら、同じアカウント・同じ保存フォルダで再試行してください。既存の別のアプリや保存先は上書きしません。

AIのインストール・起動、メール等を正本へ取り込む常時処理、バックアップと端末移行までを画面だけで完結する導入は、別途完成確認が必要です。Google連携の成功だけで、それらの動作確認を済んだことにしません。

自動ログインではサービスの正式名称を候補として用意します。各サービスのURLや認証方法は、自分のPCの設定画面で指定します。

## パスワードとPCのデータについて

PCへのログイン、就活サービスへのログイン、katazukuで記録を見るためのログインは、それぞれ別です。通常の初期設定で、長い秘密キーの貼り付けは求めません。パスワードを忘れたら、記録を保存しているPCの設定画面から再設定できます。再設定すると、ほかの端末もログアウトします。

未連携の画面には、見出しと配置だけを表示します。架空の企業、予定、メールや件数を、本人のデータの代わりに表示しません。

接続できないときは、記録を消さずに、理由と次の操作を画面で案内します。連携を解除しても、保存してあるPCの記録は削除しません。

開発者として動作を確認する場合は、[開発者向けの導入](../README.md#requirements)と[保存先の手動設定](CLOUDFLARE-SELF-HOSTING.md)を参照してください。一般向けの導入手順とは分けています。
