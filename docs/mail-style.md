# 就活メール文面ルール(最小・必須)

採用担当宛のメールを書く/返信するときに守る。**多くを盛らない。これだけは外さない。**
(出典を調べて要点だけ抽出。詳細解説は付けない=指示過多で精度が落ちるのを避けるため)

## 骨格(毎回)
1. 構成は **宛名 → 名乗り(大学名+氏名)→ 用件 → 結び → 署名**。
   署名は「氏名 / 大学・専攻・学年 / TEL / Mail」。
2. 返信は**件名を変えない(`Re:` は残す)**。新規に出すときだけ「用件/大学名 氏名」。
3. **24時間以内**・企業の営業時間内(目安10〜18時)に送る。すぐ返せなければ「取り急ぎ拝受」の一報。

## 言葉づかい(減点されやすい)
4. **「了解しました」→「承知いたしました」**。「わかりました」も使わない。
5. **お願いする側は相手基準**。自分から日時を「〜できます / 〜でしたら / 〜であれば」と指定しない。
   「ご都合いかがでしょうか」や候補の箇条書きで下手に出る。
6. **オンラインは「参加いたします」/ 対面は「伺います」**。カレンダーの会場・URLで判別する。
7. 二重敬語・バイト敬語(〜になります / よろしかったでしょうか / 〜のほう)を避ける。
   会社名は正式名称((株)に略さない)。
   **書き言葉の本文は必ず「貴社」。「御社」は話し言葉なのでメールに書かない**
   (2026-07-31: 送信済みメールに「御社」が混入し本人指摘。送る前に本文を"御社"で検索して潰す)。
7.5 **選ぶ側の言い方をしない(上から目線の禁止・2026-07-31本人指摘)**。学生は選考を受ける立場。
   - ×「また機会がございましたら**検討させていただけますと幸いです**」→ ○「またご縁がございましたら、**お声がけいただけますと幸いです**」
   - ×「貴社に**関心を持っております**」「貴社の事業に**惹かれております**」(評価する語) →
     ○「貴社について**学ばせていただきたい**気持ちは変わりません」「**お話を伺いたく存じます**」
   - 判定基準: 主語が自分で「評価・選定・検討」する動詞になっていたら書き換える。
   - **太字・記号装飾はメール本文で使わない**(プレーンテキストのみ)。

## シーン別の要点
8. **日程調整(候補提示)**: 候補は**時間帯つきで3つ以上**。曜日は必ずJSTで検算。
   **空いている日時だけを淡々と並べる**。外した日とその理由(他社インターン・別予定等)は書かない。
   「〜開始」「〜may be possible」等の補足語も付けず、日付+時間帯だけにする(2026-07-30本人指摘)。
   **日付を出す前(本人への選択肢提示も含む)に、必ずその期間のカレンダーを引いて空きを確認する**
   ("見てから話す"。埋まっている日を候補に混ぜない)。カレンダーが実態とズレている疑いがあれば先に確認。
9. **日程確定**: 日時を**復唱して確定**(取り違え防止)。「機会をいただきありがとうございます」を添える。
10. **リスケ**: お詫び → 変更依頼 → 簡潔な理由 → 代替候補を複数 → 謝意。**回数は1回まで**。前日・当日は電話を優先。
11. **お礼メール**: **最終面接のみ**送る(既存方針)。当日中・具体的な話題を一つ・簡潔に。
12. **辞退**: 理由は**「一身上の都合により」で十分**。他社比較や批判は書かない。直前・最終・内定辞退は電話を優先。
    構成は**感謝 → お詫び → 辞退の意思 → 今後のお願い**。感謝と謝罪はセットで書く。
    **3日前〜当日の辞退は電話を優先**(メールだけで済ませない)。
    結びは「またご縁がございましたら、お声がけいただけますと幸いです」や
    「貴社の益々のご発展をお祈り申し上げます」。**自分が検討する側の言い回しにしない**(7.5)。
14. **「貴社様」は誤り**(敬語の重複)。「貴社」単独か、正式社名+「様」(例: 株式会社◯◯様)にする。

## 送信の運用
13. 定型の**受諾・受領確認・日程回答は送信してよい**。
    ただし**辞退・志望度・条件交渉など本人の意思に関わるものは下書き止まりにして本人確認**する。
