# 就活の「調べる・覚える・書き写す」を、少し片づける。katazuku 就活を公開しています

メールで届く締切、いくつも開いた企業のページ、座談会のメモ。

就活では、会社を知ったり、自分のことを考えたりする前に、情報を探し直す作業が積み重なります。

そのあれこれを自分の手元にまとめるために作っているのが、オープンソースの **katazuku 就活** です。

[katazuku 就活のHP](https://katazuku-shukatsu.kotalabo.com/)

## 考える・会う・決める時間を残したい

目指しているのは、就活生の判断を全部AIに預けることではありません。

企業の資料を整理する。締切を見渡す。前に会った人との会話を思い出す。そうした準備を助けて、自分は会社を知り、人と話し、進路を決めることに時間を使えるようにしたいと考えています。

たとえば企業研究なら、事業や顧客の情報だけでなく、出典と「次に聞きたいこと」を一緒に残します。

人の記録なら、所属だけでなく、いつ、どこで会って、どんな話をしたかを残します。名前の一覧があることよりも、次に会う前に会話を思い出せることが大事です。

## 自分のPCを中心に、自分のデータを扱う

katazukuのデータの正本は、手元のPCにあるSQLiteです。閲覧アプリは、その状態を書き出したデータを読みます。

利用者全員の就活情報を作者のアカウントに集める構成にはしていません。クラウドを使いたい場合も、利用者自身のCloudflareに置くことを基本にしています。

ただし、クラウド連携を選べば閲覧用データはクラウドに送られます。ローカル中心だから何をしても外に出ない、という意味ではありません。何をどこへ置くかを、自分で確認できる構成にしたいと思っています。

## まずは、実際のメールをつながずに試せます

公開版には、データ基盤と読み取り専用のアプリ群が入っています。

最初は架空の企業・予定を用意して、PCのブラウザで見るところから試せます。Googleアカウントや、企業のマイページの認証情報は使いません。

コードを書いたことがない方向けに、Node.jsの入れ方、ターミナルの開き方、ダウンロード、起動、終了と再起動までを案内するチュートリアルを作りました。

[初めての起動を、一緒に。](https://katazuku-shukatsu.kotalabo.com/guide/first-run/)

開発者向けのコアライブラリはnpmにも公開しています。こちらはプログラムから使うためのパッケージで、閲覧アプリを試す場合はGitHubのリポジトリを使います。

```sh
npm install katazuku-shukatsu
```

## まだ開発中のところもあります

公開版は、インストールすれば就活のすべてが自動で回る完成品ではありません。

Googleとの日常的な自動同期、企業サイトのブラウザ操作、GUIを含めたクラウド一括導入は、これから整える部分です。

活動記録から就活日記を自動で作る機能も、まだ公開していません。まずは記録を根拠に短く振り返るテンプレートを用意しています。日記を作るときにも、本人が書いていない気持ちや成果をAIが埋めてしまわないことを大切にしています。

[活動記録から就活日記を作るテンプレート](https://katazuku-shukatsu.kotalabo.com/articles/job-hunting-journal/)

## 任せないことも、先に決めています

経験していない実績をESに加えない。Webテストや採用課題は本人が受ける。送信や予約、辞退などは内容を確認してから確定する。

応募先のルールを守り、自分で説明できる事実を使うことが前提です。便利にするための仕組みが、本人の知らないところで大事な判断を終わらせないようにしたいと考えています。

## 使う人と、一緒に育てたい

使ってみた感想、分からなかった手順、誤字の修正も歓迎します。コードを書ける方は、テストや機能の改善にも参加できます。

気になったらGitHubでStarを付けておくと、後から見つけやすくなります。Starは利用の条件ではありません。

[GitHubでコードを見る・参加する](https://github.com/kokotatan/katazuku-shukatsu)

HPでは、就活でAIをどう使うか、就活がつらい日の整理、開発設計についての記事も公開しています。ツールの導入が重い日には、記事のメモの型だけ使ってもらっても大丈夫です。

考える時間を、自分の手元に。少しずつ使いやすい道具に育てていきます。
